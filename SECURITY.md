# Security policy

Tegami protects files and passwords that people entrust to it. Any way to
recover plaintext or a filename without the password, to make a page
send data anywhere, to make a modified delivery open without error, or to run
a delivered file is a security defect.

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/rubyattack3r/tegami/security/advisories/new).
Do not open a public issue, and do not attach real deliveries or passwords.
If private reporting is not yet enabled on the repository, contact the
maintainers through an existing private channel instead.

The trust boundaries and what Tegami does and does not protect are documented
in the [security model](docs/security.md).
